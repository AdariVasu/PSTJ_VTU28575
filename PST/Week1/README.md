# Week 1 – Functional Programming (Java)

Solutions are standalone Java files. For LeetCode-style questions, each file contains the standard `Solution` method; rename the class/file as needed for your IDE. For HackerRank-style tasks, files include a `main` method where practical.

Topics from the lesson plan: lambda expressions, sorting/comparators, running sum, richest customer wealth, squares of a sorted array, pivot index, array transformations, and basic array operations.
